# 供应链可视化平台 · 脚本功能索引

> 原始英文文件名保持不变，确保 WorkBuddy、GitHub Actions 和历史命令继续可用。`..\*.bat` 为中文一键入口。

## 一键入口

| 中文入口 | 作用 |
|---|---|
| `运行SAP流水线.bat` | SAP 抓取 → 翻译 → 脱敏 → 生成 JSON → 校验 |
| `更新比赛页面.bat` | 使用现有脱敏工作簿，只生成 JSON、校验并构建分享版 |
| `启动页面.bat` | 启动 `127.0.0.1:8765` 本地预览 |

## 核心脚本

| 文件名 | 中文功能 | 何时使用 |
|---|---|---|
| `run_sap_pipeline.ps1` | 全流程总控 | 每日正式更新、比赛前完整重跑 |
| `generate_data.py` | Excel + 外部行情 → `dashboard_data.json` / `.js` | 数据重算 |
| `validate_dashboard_data.py` | 发布前数据安全校验 | 生成后、提交前必须执行 |
| `build_share_html.py` | 构建离线单文件分享版 | 发给评委或同事 |
| `build_cloudflare_site.mjs` | 构建 Cloudflare 内部版站点 | 内部私有部署 |
| `supplier_region.py` | 供应商地域归一化 | 地域识别规则调整 |
