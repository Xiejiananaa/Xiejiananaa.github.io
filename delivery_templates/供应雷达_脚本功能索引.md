# SAP 自动抓取与数据生成 · 脚本功能索引

> 原始英文文件名保持不变，避免破坏 `run_pipeline.py`、批处理和 WorkBuddy 的引用。日常优先使用目录中的中文 `.bat`。

## 总入口

| 文件 | 中文功能 |
|---|---|
| `run_pipeline.py` | SAP 自动化总控：抓取 → 翻译 → 脱敏 |
| `run_pipeline.bat` | 总控 Windows 双击入口 |
| `desensitize_latest.bat` | 对最新总表重新脱敏 |
| `test_export_me2l_mb51.bat` | 测试 ME2L / MB51 导出 |
| `finalize_mb51_merge.bat` | 将 MB51 合并临时文件转正 |

## SAP 抓取

| 文件名 | 中文功能 |
|---|---|
| `sap_fetcher.py` | SAP 多事务抓取主程序 |
| `sap_profiles.py` | ZWM002 / ME2L / MB51 抓取配置 |
| `connect_flow.py` | SAP 连接与登录策略 |
| `ensure_sap_gui.py` | 检查或启动 SAP GUI |
| `login_guard.py` | 登录状态确认和重试 |
| `transaction_guard.py` | 事务码打开状态检查 |
| `zwm002_hook.py` | ZWM002 工厂多选支持 |
| `discover_results_me2l_mb51.py` | 发现 ME2L / MB51 结果屏控件 |
| `test_export_me2l_mb51.py` | 验证原生导出和表头 |

## 数据处理

| 文件名 | 中文功能 |
|---|---|
| `me2l_planner.py` | ME2L 到货计划与节奏分析 |
| `mb51_processor.py` | MB51 实际收货与供应商绩效 |
| `merge_mb51.py` | MB51 增量合并与去重 |
| `finalize_mb51_merge.py` | MB51 临时合并文件转正 |
| `sap_translator.py` | 原始表 → 供应雷达总表 |
| `safety_stock.py` | 安全库存 / 补货量计算 |
| `supplier_region.py` | 供应商地域归一化 |
| `desensitizer.py` | 供应雷达工作簿脱敏 |
| `desensitize_latest.py` | 最新总表按档位脱敏 |
| `dingtalk_push.py` | 可选：推送钉钉 AI 表格 |
| `dashboard_contract.py` | 看板 JSON 数据契约 |
| `update_dashboard_data.py` | 旧版看板 JSON 生成器，保留作参考 |

## 安全边界

- `.env` 不进入交付包。
- 原始 Excel、MB51、ME2L、消耗表和内部数据不进入公开包。
- `vendor`、`.venv`、`__pycache__`、`logs`、`backup` 不进入交付包。
- 比赛公开数据只能使用部分脱敏模式，并仅保留工厂 1501。
