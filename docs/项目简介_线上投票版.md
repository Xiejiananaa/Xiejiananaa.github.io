# 供应雷达 · 线上投票项目简介

供应雷达是一套面向供应链保供场景的数智化决策平台，围绕“数据与展示分离”构建。系统自动抓取 SAP库存、采购计划与实际收货数据，完成翻译、清洗、计算和脱敏，统一生成标准 JSON数据接口，并通过静态可视化页面呈现物料风险、供需缺口、补货建议、供应商履约、库存资金、生产推演和市场情报。平台动态计算健康指数、ATP 承诺量、库存覆盖天数、安全库存与预警状态，帮助业务人员快速识别高风险物料和异常供应商。WorkBuddy负责每日外部资讯与数据协同，GitHub Actions实现自动校验和发布。比赛版仅展示工厂 1501 部分脱敏数据，兼顾真实业务价值、数据安全与可推广性，服务于日常保供和比赛展示。
